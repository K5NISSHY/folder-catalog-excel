# Folder Catalog Excel — 要件定義書

作成日: 2026-11-24 / 作成: Strata アシスタント（ユーザーの依頼に基づく） / 状態: **承認済み（2026-11-24・CSVオプション追加の改訂を反映）**

## 0. 要求定義

### 0.1 背景・課題

共有フォルダやプロジェクトフォルダの中身を把握したい場面は多い（棚卸し、引き継ぎ、保存期限の確認、不要ファイルの洗い出し、容量調査）。Windows には `tree` コマンドがあるが、出力は**文字のツリー図**であり、次の理由で実務ではそのまま使えない。

| 観点 | `tree`（コマンドプロンプト） | このツール（Excel出力） |
| --- | --- | --- |
| 出力の形 | 文字のツリー図（`└──` などの罫線文字）。コピーすると崩れることがある | 1行=1ファイルの表。ソート・フィルタ・数式が使える |
| ファイルサイズ | 出ない（`tree` は名前のみ） | 出る（KB・合計・フォルダ別集計） |
| 更新日時・作成日時 | 出ない | 出る（新しい順・古い順に並べ替え可能） |
| 拡張子・種類 | 分からない | 拡張子別の件数・合計サイズを集計 |
| 階層の深さ | 罫線の数でしか分からない | 階層レベル・フォルダ名が別列（フィルタで「3階層目だけ」が可能） |
| 大容量フォルダ | 画面に収まらず、スクロールで全体像が掴めない | 件数・合計サイズが冒頭に表示され、集計シートで把握できる |
| 後処理 | テキストを表に直す作業が発生（コピペ→列の分離→整形） | 完成した表がそのまま出てくる |
| 文字化け | コードページ（`chcp`）や罫線文字で崩れることがある | Excelに直接書くため影響ない |

`tree` は「ざっと見る」用途、Excel出力は「**並べ替えて判断する・人に渡す**」用途、という違いを記事で示す。

### 0.2 解決したいこと

- フォルダを選ぶ → 実行するだけで、**中身の目録がExcelで出てくる**
- 出てきた表を**そのままフィルタ・ソート・集計に使える**（「1年更新されていないファイル」「100MB超」「.tmp だけ」など）
- 実行前に「何件・どのくらいの量になるか」が分かり、**間違えて巨大フォルダを走らせても止める判断ができる**
- 失敗（アクセスできないフォルダ、長すぎるパス）で**落ちずに、失敗した箇所だけ一覧に残る**

### 0.3 成功の目安（受け入れの目線）

| 観点 | 目安 |
| --- | --- |
| 時間 | 1万ファイル規模のフォルダを数分で目録化できる。実行中は進捗が見え、フリーズしない |
| 正確性 | 収集件数とExcelの行数が一致する。アクセス不可のフォルダは行数から消えず「エラー一覧」に記録される |
| 使いやすさ | ダブルクリックで起動、フォルダ選択→実行→Excelが開く。既存のExcelファイルは絶対に上書きしない |
| 比較できる | 同じフォルダで `tree /F` と並べても劣らない情報量（サイズ・日時・集計）がExcel側にある |

## 1. 要件定義

### 1.1 目的

指定フォルダ配下を再帰的に走査し、**ファイル一覧・フォルダ集計・拡張子集計・エラー一覧**を1つのExcelワークブックに出力する単一画面のWindowsツール。

### 1.2 機能要件

| ID | 要件 | 優先度 | 達成状況 |
| --- | --- | --- | --- |
| FR-1 | 対象フォルダをダイアログで選択できる（手入力も可） | Must | 未着手 |
| FR-2 | 選択したフォルダ配下を再帰的に走査し、ファイルとフォルダを収集する | Must | 未着手 |
| FR-3 | 実行前に**事前プレビュー**（想定件数・合計サイズ・最深階層・対象フォルダの絶対パス）を表示し、実行はプレビュー後にできる | Must | 未着手 |
| FR-4 | Excelシート「一覧」を出力する。列は No / 相対パス / 階層レベル / 直下のフォルダ / ファイル名 / 拡張子 / サイズ(KB) / 更新日時 / 作成日時 | Must | 未着手 |
| FR-5 | Excelシート「フォルダ集計」を出力する（フォルダ単位のファイル数・合計サイズ・最深階層） | Must | 未着手 |
| FR-6 | Excelシート「拡張子集計」を出力する（拡張子単位の件数・合計サイズ・最大ファイル） | Must | 未着手 |
| FR-7 | 見出し行に**フィルタ**を付け、先頭行を固定し、列幅を調整する（開いてすぐ使える書式） | Must | 未着手 |
| FR-8 | 出力ファイル名は `<フォルダ名>_目録_<YYYYMMDD_HHMM>.xlsx`。同名ファイルが存在する場合は**自動で連番を付けて上書きしない** | Must | 未着手 |
| FR-9 | 除外オプション: 隠しファイル／システムファイル、特定フォルダ（`.git`, `node_modules`, `$RECYCLE.BIN`, `System Volume Information`, `desktop.ini` 等）を既定で除外し、チェックで解除できる | Must | 未着手 |
| FR-10 | アクセス拒否・長すぎるパスなどの失敗は**クラッシュさせず**、シート「エラー一覧」にパスと理由を記録する | Must | 未着手 |
| FR-11 | 走査は別スレッドで行い、GUIはフリーズしない。進捗（処理件数・現在のフォルダ）と**中止ボタン**を備える | Must | 未着手 |
| FR-12 | 出力先フォルダを選択できる（既定は対象フォルダの親） | Should | 未着手 |
| FR-13 | 件数上限（安全装置）を指定できる（既定 200,000 件。超過時は警告して停止） | Should | 未着手 |
| FR-14 | 完了時に生成ファイルのパスと件数を表示し、Excelを起動するか選べる | Should | 未着手 |
| FR-15 | 前回実行の設定（除外オプション・上限）を覚えておく | Could | 未着手 |
| FR-16 | **CSVでも書き出せる**（チェックボックスのオプション。既定はオフ）。ONにすると同じ目録を **UTF-8（BOM付き）** のCSVでも出力し、Excelと同じベース名にする | Must | 未着手 |

### 1.3 非機能要件

| ID | 要件 | 優先度 | 達成状況 |
| --- | --- | --- | --- |
| NFR-1 | Python 3 標準ライブラリ＋**openpyxl のみ**で動く（追加ライブラリ禁止、`pip install` 禁止） | Must | 未着手 |
| NFR-2 | GUIは Tkinter（ttk）。exe化・インストール手順は要求しない（`起動.bat` で起動） | Must | 未着手 |
| NFR-3 | 大容量でも破綻しない（openpyxl の write_only モード等を使い、10万件規模でメモリが爆発しない） | Must | 未着手 |
| NFR-4 | 日本語ファイル名・日本語フォルダ名・スペース入り・長めのパスで正しく動く | Must | 未着手 |
| NFR-5 | 既存ファイルを上書きしない・ファイルの移動/削除/リネームを**一切しない**（読み取り専用） | Must | 未着手 |
| NFR-6 | 実行環境はユーザーのPC（Windows）。ネットワークドライブのパスも対象にできる | Must | 未着手 |
| NFR-7 | 単体テスト（収集ロジック・ファイル名生成・除外判定）を `test_*.py` で用意し、機械判定で PASS すること | Must | 未着手 |
| NFR-8 | 記事用の検証に使う**サンプルフォルダ生成スクリプト**（ダミーのみ・個人情報なし）を用意する | Must | 未着手 |

### 1.4 設計方針

- 走査は `os.scandir` を自前で再帰（`os.walk` でも可）し、`PermissionError` などをその場で拾ってエラー一覧へ積む
- 収集データは**行のタプルを順にためる**軽量な形にし、Excel書き出しは openpyxl の `write_only=True` でストリーム的に書く
- 件数が多い場合はプレビューで警告（例: 5万件超は「時間がかかります」）
- 画面は既存ツール（pdf-split-unified）と同じ思想: **上に入力、下に「プレビュー」→「実行」**、実行前に全件（ここでは要約）が見える

### 1.5 対象外（スコープ外）

- ファイルの**移動・削除・リネーム・圧縮**（読み取り専用の目録のみ）
- 重複ファイルのハッシュ判定（別ツール C2 の領域）
- JSON などの **Excel・CSV 以外**の出力形式【改訂: 承認時にユーザーから「CSVはチェックボックスのオプションで入れたい」との指定があり、CSVを FR-16 としてスコープ内へ移動した】
- 実行履歴のデータベース化、常駐、スケジューラ連携
- 権限の昇格（管理者としてしか読めないフォルダの強制走査）
- 実行ファイル（exe）化、インストールインストーラー

## 2. 機能定義（スクリプト毎の入出力・データ仕様）

| スクリプト | 役割 | 入力 | 出力 |
| --- | --- | --- | --- |
| `scan_core.py` | 走査と収集（GUI非依存） | 対象パス、除外設定、件数上限 | 行データ（ファイル情報）＋フォルダ集計＋拡張子集計＋エラー一覧＋進捗コールバック |
| `catalog_writer.py` | Excel書き出し（GUI非依存）。CSV書き出しもここ（FR-16） | 上記の集計データ、出力パス、CSVのON/OFF | `.xlsx`（一覧／フォルダ集計／拡張子集計／エラー一覧／サマリー）、CSV ON時は `一覧` と `フォルダ集計` のUTF-8（BOM付き）CSV |
| `folder_catalog_excel.py` | Tkinter GUI | 画面入力 | 事前プレビュー表示、実行、完了表示 |
| `test_folder_catalog_excel.py` | 単体テスト | 一時フォルダに作った見本ツリー | 機械判定の PASS/FAIL |
| `tools/make_samples.py` | 検証用サンプルフォルダ生成 | — | `samples/` 配下に日本語名・多階層・各種拡張子のダミーツリー |
| `tools/run_sample_catalog.py` | サンプルに対する実行走査＋Excel生成 | — | `samples/検証結果/` に `.xlsx` と機械判定結果 |
| `tools/tree_compare.py` | 記事用の比較材料生成 | 同一のサンプルフォルダ | `tree /F` のテキスト出力と、Excel側の件数・サイズ集計の突き合わせ結果 |

### 2.1 Excel のシート構成

| シート | 内容 |
| --- | --- |
| `サマリー` | 対象フォルダ、実行日時、収集ファイル数、フォルダ数、合計サイズ、除外設定、エラー件数 |
| `一覧` | 1行=1ファイル（FR-4 の列）。見出しにフィルタ、先頭行固定 |
| `フォルダ集計` | 1行=1フォルダ（ファイル数・合計サイズ・最深階層） |
| `拡張子集計` | 1行=1拡張子（件数・合計サイズ・最大ファイルサイズ） |
| `エラー一覧` | 走査に失敗したパスと理由（FR-10） |
