# フォルダ目録 Excel 作成ツール（folder-catalog-excel）

フォルダを 1 つ選ぶだけで、その配下を再帰的に走査して **Excel の目録**を作るツールです。
`tree` コマンドの文字のツリー図ではなく、**フィルタ・ソート・集計できる表**として出力します。

対象フォルダの中身を読むだけで、**ファイルの移動・削除・リネーム・上書きは一切しません**（読み取り専用）。

---

## できること

- 指定フォルダ配下の**全ファイル一覧**（相対パス・階層レベル・サイズ・更新日時・作成日時）
- **フォルダ単位の集計**（直下／配下のファイル数と合計サイズ、配下の最深階層）
- **拡張子単位の集計**（件数・合計サイズ・最大ファイル）
- **アクセスできないフォルダなどの失敗**を「エラー一覧」に記録（落ちない）
- 実行前に**事前プレビュー**（想定件数・合計サイズ・最深階層）を確認してから実行
- 大量ファイルでも破綻しにくい書き出し（openpyxl の `write_only` モード）
- 任意で **CSV（UTF-8・BOM 付き）** も同じベース名で出力

## 必要な環境

| 区分 | 名称 |
| --- | --- |
| OS | Windows（ネットワークドライブも対象にできます） |
| 実行環境 | Python 3.10 以降（このリポジトリには `.venv` がある構成を想定。受け取り側は `py -3` でも可） |
| ライブラリ | openpyxl のみ（Tkinter は Python 同梱。未インストールなら `起動.bat` が初回に自動で入れます） |

## 使い方

1. **`起動.bat`** をダブルクリック（`.venv` があればそれを使い、無ければ `py -3` で起動します。openpyxl が入っていなければ、この時点で `pip install --user openpyxl` を自動実行します）
2. **対象フォルダ**を「参照…」で選ぶ（手入力も可。ネットワークパスも貼れます）
3. **出力先フォルダ**を決める（未設定なら対象フォルダの親が自動で入ります）
4. 必要なら除外オプションと件数上限を調整する
5. **「プレビュー」**を押す → 想定件数・合計サイズ・最深階層・エラー件数を確認する
6. **「実行」**を押す → Excel（必要なら CSV）が作られ、開くか聞かれます

実行中は別スレッドで走るため画面は固まりません。進捗（処理件数と現在のフォルダ）が下部に表示され、
**「中止」**で任意の時点で打ち切れます（途中まででも実行すれば目録になります）。

### 除外オプション

| 項目 | 既定 |
| --- | --- |
| 隠しファイル／システムファイル（名前の先頭が `.` のものを含む） | 除外する |
| 既定の除外名: `.git`, `node_modules`, `$RECYCLE.BIN`, `System Volume Information`, `desktop.ini`, `Thumbs.db` | 除外する |
| CSV も書き出す（UTF-8・BOM 付き） | オフ |
| 件数上限（安全装置。0 で無制限） | 200,000 件 |

チェックを外すと除外せずに取り込みます。件数上限に達した場合は途中で停止し、
その旨がサマリーとエラー一覧に残ります（大量フォルダを誤って走らせたときの保険）。

## 出力されるファイル名

```
<フォルダ名>_目録_<YYYYMMDD_HHMM>.xlsx
```

同名のファイルが既にある場合は、**上書きせず**に `(2)`, `(3)`… と連番が付きます。
CSV を ON にすると、同じ連番で次の 2 種類も出てきます。

```
<フォルダ名>_目録_<YYYYMMDD_HHMM>_一覧.csv
<フォルダ名>_目録_<YYYYMMDD_HHMM>_フォルダ集計.csv
```

## Excel のシート構成

| シート | 内容 |
| --- | --- |
| サマリー | 対象フォルダ、実行日時、収集ファイル数・フォルダ数、合計サイズ、最深階層、除外設定、エラー件数 |
| 一覧 | 1 行 = 1 ファイル。`No / 相対パス / 階層レベル / 直下のフォルダ / ファイル名 / 拡張子 / サイズ(KB) / 更新日時 / 作成日時` |
| フォルダ集計 | 1 行 = 1 フォルダ。`No / フォルダ相対パス / 階層レベル / 直下ファイル数 / 直下合計サイズ(KB) / 配下ファイル数 / 配下合計サイズ(KB) / 配下最深階層` |
| 拡張子集計 | 1 行 = 1 拡張子。`No / 拡張子 / 件数 / 合計サイズ(KB) / 最大ファイルサイズ(KB) / 最大ファイルの相対パス` |
| エラー一覧 | 走査に失敗したパスと理由。`No / 種別 / パス / 理由` |

「一覧」以降のシートは**見出し行にフィルタ**、**先頭行固定**、**列幅調整**済みで、開いてすぐ使えます。

よくある使い方の例:

- 「1 年以上更新されていないファイル」→ 更新日時でソート、またはフィルタ
- 「100MB 超」→ サイズ(KB) で数値フィルタ
- 「`.tmp だけ`」→ 拡張子でフィルタ
- 「3 階層目だけ」→ 階層レベルでフィルタ
- 「どのフォルダが容量を食っているか」→ フォルダ集計の配下合計サイズでソート

## `tree` コマンドとの違い

| 観点 | `tree /F` | このツール |
| --- | --- | --- |
| 出力 | 罫線文字のツリー図（コピーすると崩れることがある） | 1 行 = 1 ファイルの表 |
| ファイルサイズ | 出ない | 出る（KB・合計・フォルダ別・拡張子別） |
| 更新日時・作成日時 | 出ない | 出る（並べ替え可能） |
| 階層の深さ | 罫線の数でしか分からない | 階層レベルが別列（絞り込める） |
| 拡張子別まとめ | 分からない | シート 1 枚に集計 |
| 後処理 | テキストを表に直す作業が必要 | 完成した表が出る |
| 失敗した場所 | 画面に流れて消える | エラー一覧に記録 |

## 注意点

- **読み取り専用**です。対象フォルダ内のファイルは変更・移動・削除せず、既存の出力ファイルも上書きしません
- 管理者権限がないフォルダは読めません。その場合はエラーとして一覧に残り、走査は止まりません
- 260 文字を超える長いパスは、Windows の拡張パス表記で自動的に再試行します。それでも失敗したものはエラー一覧に出ます
- シンボリックリンクやジャンクションは、ループ防止のため**中までは走査しません**（フォルダ自体は一覧に出ます）
- サイズは KB に直した整数です（端数は四捨五入。0 バイトは 0 KB）。合計はバイト単位で計算しているため、行の KB を単純合計すると数 KB ずれることがあります
- 日時は `YYYY-MM-DD HH:MM:SS` の文字列で書き出します（Excel 上の並べ替え・フィルタはそのまま使えます）
- 相対パスの区切りは `/` です。対象フォルダ直下のファイルの「直下のフォルダ」は `(直下)` と表示します
- 設定（除外・上限・CSV）は**同じ起動中**は記憶されますが、ファイルには保存されません
- 初回起動時、openpyxl が未インストールなら `起動.bat` が `pip install --user openpyxl` を実行します。このときだけインターネット接続が必要です（入っていればチェックだけで、インストールは走りません）
- `起動.bat` は **Shift-JIS (CP932)** 保存です。UTF-8 に変換すると cmd.exe が行を誤読して起動しなくなります
- 件数が多い場合はプレビューで警告を表示します。数十万件規模では件数上限を調整して分割してください

## 開発・検証

```
.venv\Scripts\python.exe -m unittest -v test_folder_catalog_excel   # 単体テスト
.venv\Scripts\python.exe tools\make_samples.py                      # 検証用サンプル生成
.venv\Scripts\python.exe tools\run_sample_catalog.py                # 実行走査＋機械判定
.venv\Scripts\python.exe tools\tree_compare.py                      # tree /F 形式との突き合わせ
```

`tools/make_samples.py` は個人情報や実データを一切使わない**ダミーのみ**のサンプルツリーを
`samples/` に作ります。`tools/run_sample_catalog.py` と `tools/tree_compare.py` の結果は
`samples/検証結果/` に出力されます（次回以降の走査では自動で除外されます）。

なお、ダミーのサンプルツリー自体（87 ファイル・約 42 MB）はリポジトリに入れていません。
`tools/make_samples.py` で再現できるためです。実行例として `samples/検証結果/` の
Excel・CSV・`tree_F.txt` だけは同梱しています。

| ファイル | 役割 |
| --- | --- |
| `scan_core.py` | 走査と収集（GUI 非依存） |
| `catalog_writer.py` | Excel・CSV 書き出し（GUI 非依存） |
| `folder_catalog_excel.py` | Tkinter GUI |
| `test_folder_catalog_excel.py` | 単体テスト（標準 `unittest`） |
| `tools/make_samples.py` | 検証用サンプルフォルダ生成 |
| `tools/run_sample_catalog.py` | サンプルでの実行走査＋機械判定 |
| `tools/tree_compare.py` | `tree /F` 形式との比較材料生成 |
| `起動.bat` | 起動スクリプト |
| `docs/PROJECT_DOCUMENT.md` | 要件定義書と検証結果 |
